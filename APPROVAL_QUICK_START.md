# Quick Start Guide - Two-Level Approval Workflow

## 🚀 Getting Started in 5 Minutes

### What's New?
Your daily checks now require **two approvals** before you can export to PDF:
1. **Supervisor Approval** (Step 1)
2. **Technical Manager Approval** (Step 2)

This replaces printed paper logbooks with a digital PDF export system.

---

## 📋 Step-by-Step User Guide

### Step 1: Complete Your Daily Check ✓

1. Open the inspection system
2. Create a new daily check
3. Enter all equipment readings and data
4. Click "STOP DAILY CHECK" to complete the session
5. System shows the completion summary screen

### Step 2: Supervisor Approval 👤

On the completion screen, you'll see the **Approval Checklist** section:

#### Section 1: Supervisor Approval

```
┌─────────────────────────────────────┐
│ 1️⃣  Supervisor Approval            │
│                                     │
│ [Enter Supervisor Name]             │
│ [Canvas for signature drawing]      │
│ [Clear] [Capture]                   │
│                                     │
│ [👤 Approve as Supervisor]          │
└─────────────────────────────────────┘
```

**What to do:**
1. **Enter Name**: Type the supervisor's full name
2. **Draw Signature**: Click on the signature canvas and draw with your mouse/trackpad or touch
3. **Capture**: Click the "📸 Capture" button to save the signature
4. **Approve**: Click "Approve as Supervisor" button
5. **Wait**: System saves and confirms approval ✓

**Helpful Tips:**
- Draw a quick signature (initials are fine)
- If you make a mistake, click "Clear" and redraw
- Click "Capture" after drawing (it saves the image)
- You'll see the signature preview after capturing

---

### Step 3: Technical Manager Approval 👔

Once supervisor approves, the **Technical Manager** section unlocks:

#### Section 2: Technical Manager Approval (Unlocked after Step 1)

```
┌─────────────────────────────────────┐
│ 2️⃣  Technical Manager Approval      │
│                                     │
│ [Enter Tech Manager Name]           │
│ [Canvas for signature drawing]      │
│ [Clear] [Capture]                   │
│                                     │
│ [👔 Approve as Technical Manager]   │
└─────────────────────────────────────┘
```

**What to do:**
1. **Enter Name**: Type the technical manager's full name
2. **Draw Signature**: Click on the signature canvas and draw with your mouse/trackpad or touch
3. **Capture**: Click the "📸 Capture" button to save the signature
4. **Approve**: Click "Approve as Technical Manager" button
5. **Wait**: System saves and confirms approval ✓

**Note**: This section is locked 🔒 until supervisor approves!

---

### Step 4: Export to PDF 📄

Once **both approvals are complete** ✅, the PDF export becomes available:

```
📥 Export Data

┌──────────────┐ ┌──────────────┐ ┌────────────┐
│ 📄 CSV       │ │ 📊 XLSX      │ │ ✅ PDF     │
│ Available    │ │ Available    │ │ UNLOCKED   │
└──────────────┘ └──────────────┘ └────────────┘
```

**What to do:**
1. Click "✅ PDF" button
2. Browser downloads the PDF file
3. PDF includes all data + signatures
4. Use the digital PDF instead of printing

## ❓ FAQ - Common Questions

### Q: What if I make a mistake while drawing the signature?
**A:** Click the "🗑️ Clear" button to erase and redraw. You can redo it as many times as needed before clicking "Approve".

### Q: Can I remove an approval after it's been submitted?
**A:** Yes! Click the "🔄 Remove Approval" button to undo it. You'll need to get the approval again.

### Q: Why can't I approve as Technical Manager yet?
**A:** The system requires Supervisor approval first. This is a safety feature. Once supervisor approves (you'll see ✓ badge), the Technical Manager section will unlock.

### Q: I forgot to capture my signature. What happens?
**A:** The approve button will be disabled (grayed out) if signature isn't captured. Make sure you click "Capture" before "Approve".

### Q: Can I export to CSV/XLSX without approvals?
**A:** Yes! CSV and XLSX exports are always available. Only PDF export requires both approvals.

### Q: Where does my signature go?
**A:** Your signature is stored securely in the database and included in the PDF export. It serves as a digital record.

### Q: What if I export PDF, then remove an approval later?
**A:** The exported PDF file stays as is (already saved). The approval status is updated in the system. If you remove approval later, you'll need to get both approvals again to export a new PDF.

### Q: Do I need to print the PDF?
**A:** No! The whole point is to use the digital PDF instead of printing. Just save it or email it as needed.

## 💡 Pro Tips

### Tip 1: Use Consistent Names
Use the same name format each time (e.g., "John Doe" not "J. Doe" or "john doe")

### Tip 2: Keep Signature Simple
You don't need a fancy signature. Initials or a simple mark works fine.

### Tip 3: Signature Preview
Always check the signature preview before clicking "Approve". If it looks blank or wrong, click "Clear" and try again.

### Tip 4: Save PDFs Organized
Create a folder on your computer: `Daily Checks / 2026 / August`  
Download PDFs there for easy finding.

### Tip 5: Use Browser's Print Function
If you absolutely must print: 
1. Open the PDF
2. Press Ctrl+P (or Cmd+P on Mac)
3. Select your printer
4. Only then print (but the goal is to not print!)

## 🆘 Troubleshooting

### Problem: "Signature canvas looks empty"
**Solution**: Try drawing in the center of the canvas with larger strokes. Ensure your mouse/touchpad is working.

### Problem: "Capture button does nothing"
**Solution**: Make sure you drew something on the canvas. Blank signatures won't capture.

### Problem: "Approve button is grayed out/disabled"
**Solution**: Check that you've entered a name AND captured a signature.

### Problem: "Technical Manager section still locked"
**Solution**: 
1. Scroll up to check supervisor section shows ✓ badge
2. Try refreshing the page (F5)
3. Make sure supervisor's approve action completed (look for "✅ Supervisor approval confirmed" message)

### Problem: "PDF export still says 'Locked'"
**Solution**:
1. Verify both sections show ✓ badges
2. Refresh the page
3. Try again

### Problem: "Browser didn't download the PDF"
**Solution**:
1. Check if file is in your Downloads folder
2. Check browser's download settings
3. Try a different browser
4. Contact IT support if problem continues
